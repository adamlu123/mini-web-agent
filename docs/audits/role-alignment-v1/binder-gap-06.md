## Generalizable pre-write principles

1. Build a read/write identity table before mutation.
2. Expand paths and inspect active profile/process/service identity.
3. Unresolved hard gates block replacement directories/profiles/servers/targets.
4. Offline audit compares exact score-facing predicates; runtime Binder uses
   only task-visible evidence.
5. Inspect → write → reload/reopen → read back from the same canonical surface.
6. Separate visual plausibility from exact persisted/scored identity.
7. Attribute infrastructure, Actor, Binder, and evaluator conflicts separately.
