# Actor strategy persistence

## Failure patterns

- **047:** failed UI route remained alive through asset parsing, registry edits,
  and speculative patching; live game stayed intermediate.
- **048:** input mapping failed, then decompilation/asset inspection returned to
  the same UI route; no completion/save.
- **050:** blocked source acquisition displaced minimum RPP creation; repair used
  synthetic sources.
- **054:** visibly defective polygon masking remained the dominant hypothesis.
- **055:** native project existed, but visual failures were discovered late and
  repair did not converge.
- **056:** structural project converged; title geometry did not.
- **059:** failed image import led to XML/JAR speculation and no canonical GGB.
- **071:** read-only Desktop was proven, but privilege/mount workarounds
  continued.
- **088:** outputs existed, but macro functionality was deferred until too late.

## Successful controls

- **039:** compaction preserved a working API/state route and idempotent
  moderation actions.
- **095:** missing-source blocker triggered legitimate recovery, then native
  construction and validation.

## Observable principles

1. Persistence converges when it preserves a tested invariant.
2. Thrash occurs when a falsified hypothesis remains active.
3. A route switch is productive only if evaluator-facing state changes.
4. Canonical artifact existence outranks internal progress.
5. Late validation creates stable wrong basins.
6. Compaction amplifies the current strategy; count alone is not causal.
7. After a blocker, calls should falsify, mutate, or read back one bounded
   alternative.
