## Productive persistence

- each attempt changes evidence state;
- bounded search switches to an authorized source;
- exact source identity is verified;
- a minimum evaluator-facing artifact is created;
- search stops once blocked and asks once or records a truthful blocker.

## Thrash

- repeating the same blocked URL;
- broad speculative search after a decisive gate;
- synthetic substitution where provenance matters;
- continuing without new evidence.

## Recovery principles

1. Verify source identity before editing.
2. Ask once for genuinely missing user-controlled resources.
3. Recovery authorization permits exact originals, not fabrication.
4. Preserve native structure even when content remains unknown.
5. Create a truthful minimal artifact early.
6. Persistence must produce new evidence.
