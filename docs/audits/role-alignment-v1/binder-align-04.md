## General principles

1. Offline analysis must inspect the evaluator’s exact extraction/predicates,
   but runtime Binder remains evaluator-blind.
2. Inventory dynamic state immediately before execution.
3. Unresolved Critic contradictions must not silently choose one side.
4. Distinguish reasonable preservation/roll-forward semantics from the actual
   task-visible target population.
5. Binder verification does not establish evaluator agreement.
6. Actor capacity helps verify/construct, but cannot rescue a wrong contract.
