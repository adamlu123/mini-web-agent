deterministic, and attached to an existing artifact.

## When context helps

- exact existing file/field/object;
- deterministic local defect;
- preserved source choices/session/geometry;
- bounded continuation;
- canonical post-save readback.

## When context does not help

- wrong strategy or semantic model;
- invented transcript/taxonomy/values;
- whole-project reconstruction;
- missing artifact;
- broken infrastructure;
- hidden evaluator facts.

## Bounded repair requirements

1. Return finding to original Actor.
2. Name the exact defect and canonical target.
3. Preserve all proven invariants.
4. Snapshot and allow one limited continuation.
5. Save/reload and recheck the evaluator-facing surface.
6. Roll back failed local repairs; disallow unsnapshotted remote/session repair.
7. Keep ambiguous facts unresolved.
